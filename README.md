# Home Assistant add-ons

[![Add repository to Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fnooniansoong%2Fhassio-addons)

Add this repository in Home Assistant: **Settings → Add-ons → Add-on store → ⋮ → Repositories**
and enter `https://github.com/nooniansoong/hassio-addons`.

## Add-ons

### [TapTap Multi](./taptap_multi)

Local Tigo optimizer monitoring for **multiple Tigo CCAs** (one RS485 converter such as an
Elfin EW11 per CCA), published to Home Assistant via MQTT discovery.

Fork of the [TapTap add-on](https://github.com/litinoveweedle/hassio-addons/tree/main/taptap)
by litinoveweedle, built on [taptap](https://github.com/litinoveweedle/taptap) /
[taptap-mqtt](https://github.com/litinoveweedle/taptap-mqtt) (protocol work by
[willglynn/taptap](https://github.com/willglynn/taptap)). Licensed under Apache 2.0.
